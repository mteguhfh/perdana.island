# Perdana Island GNOME v79

This source update targets GNOME Shell 50 and 51. The source can be published on `main` independently of a versioned GitHub binary release; publishing a release still requires the `v79` tag.

## Changes

- Adapts the Activity API and progress tracking merged in [PR #24](https://github.com/txtperdana/perdana.island/pull/24). Compatible applications can report named work over the session bus; the Downloads watcher also detects common partial-file suffixes and aria2 totals.
- Updates Activity rows without rebuilding the page on each progress tick. Completed downloads stay visible until selected; selecting one opens its file and removes the row. Completed application activities expire after 4.5 seconds.
- Keeps the monitor scan resilient to temporary directory enumeration errors and file-renaming gaps.
- Fixes smart music detection for podcast/episode titles from otherwise trusted music providers.
- Adapts Quick Capture parsing improvements from PR #25: Indonesian and English weekdays, dates, clock formats, periods, and priorities, with invalid date/time text preserved. The existing task/note flow remains intact.
- Adapts the nested, versioned backup format from PR #26 while keeping restore compatibility for existing flat local backups. Machine-only preferences are filtered and imported entries are bounded and validated.
- Excludes preview screenshots from the GNOME extension archive while retaining them in the repository README.
- Defers cross-monitor movement (PR #17) as requested.
- Keeps GNOME and KDE package versions independent; v79 is GNOME-only and the Plasma package remains on v76.

## Verification

- `npm test`: regression tests cover Quick Capture language parsing, both backup formats, clipboard privacy, Activity progress, and music classification.
- JavaScript syntax checks pass for the extension and helper modules.
- GNOME schemas compile and `scripts/build-gnome.sh` produces the v79 archive.
- Archive contents are checked for the metadata, schemas, progress helper, and runtime icons; preview-only screenshot files are excluded.
- Static layout review against the local v2 prototype: page widths and the 256 px expanded height were checked; Notes and Settings keep their own scroll regions and right-side safety space. The prototype itself is not included in the clean source repository.

Shexli 0.2.1 was attempted on the v79 archive under Python 3.14, but the analyzer exited with SIGSEGV (139) without producing findings; this is inconclusive, not a pass. No logout or desktop restart was performed, so this source push does not activate v79 in a running GNOME Shell session.
