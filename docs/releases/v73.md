# Perdana Island v73

## GNOME Shell extension

- Ports the reduced-motion-aware transitions from PR #12 into the current GNOME extension: island open/close, page changes, selected-tab feedback, playback progress, lyrics movement, notices, and button response.
- Adds draggable tab ordering. The order persists, and the first visible tab becomes the default page opened from the resting island.
- Adds island positioning by dragging the resting pill or open header. The island can snap to Top, Bottom, Left, or Right, or stay at a free position; position controls are also available in Settings → Island.
- Moves smart music detection to its own Settings → Music section.
- Carries forward the current GNOME layout fixes for settings safe space, the island's centered position, and brightness OSD monitoring.
- Continues to honor GNOME's reduced-motion preference for island and page transitions.

## KDE Plasma package

There are no KDE feature changes in v73. Its package metadata is aligned to the shared version number.

## PR 12 and PR 13 status

[PR #12](https://github.com/txtperdana/perdana.island/pull/12) and [PR #13](https://github.com/txtperdana/perdana.island/pull/13) were closed without being merged. Their branches targeted an older v70-era `main`; after the project advanced, GitHub reported conflicts and the code had diverged. PR #13 also depended on PR #12. The changes were reviewed and manually adapted together against the current codebase for v73, rather than attempting to merge the stale branches. The PRs remain visible for their authorship and implementation details.

### Adapted from PR #12: motion

- Open and close easing, short page transitions, selected-tab motion, and control press feedback.
- Smooth media progress and lyric movement, with reduced-motion handling.
- Lightweight focus-ring redraw behavior and transitions for notices and notes.

### Adapted from PR #13: layout

- Drag tabs to persist a custom order; the first visible tab becomes the default opening page.
- Drag the island to a screen edge or a free position, with corresponding choices in Settings → Island.
- Retains the placement and tab-order settings when island size or monitor geometry changes.
