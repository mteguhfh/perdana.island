# Perdana Island v70

## GNOME Shell extension

- Adds an optional session greeting. On first use it shows the configured welcome; later desktop login sessions show the returning message. It records the session identifier locally and displays a greeting at most once in that session.
- Greeting settings choose the Linux account name, device name, or a custom name. Both messages are editable and accept `{name}` as a placeholder. The settings panel includes separate preview actions.
- Splits Settings into Island, Greeting, Reminders, and Tabs side sections. Each section scrolls in its own content area, with a right-side gutter to keep controls clear of the scrollbar.
- Schedules an undelivered greeting again when the island becomes visible or closes, so opening the panel during login does not consume the greeting.

## KDE Plasma package

The KDE widget has no feature changes in v70. Its package version is aligned with GNOME so both desktop archives can be attached to the same project release.

## Packages

- `Perdana-Island-GNOME-v70.shell-extension.zip` for GNOME Shell 50 and 51.
- `Perdana-Island-KDE-Plasma-v70.zip` for KDE Plasma 6.

## Verification

- `./scripts/validate.sh`: checks JavaScript syntax, metadata, GSettings schema compilation, shared version numbers, archive contents, and package generation.
- Runtime interaction still requires loading the packaged v70 extension in a GNOME session; building the archives does not change the installed extension.
