# Perdana Island v76

## GNOME Shell extension

- Corrects the Plus Jakarta Sans helper text in **Settings → Island → Font**.
- The extension uses the system-installed Plus Jakarta Sans family when available and falls back to Cantarell when it is unavailable. The font is not bundled in the extension.

## KDE Plasma package

No widget feature changes. Package metadata is aligned to v76.

## Packages

- `Perdana-Island-GNOME-v76.shell-extension.zip` for GNOME Shell 50 and 51.
- `Perdana-Island-KDE-Plasma-v76.zip` for KDE Plasma 6.
