# Perdana Island v78.3

## Fixes

- Positions Quick capture beside the clock, with the date, time, and action button kept inside the header's safe inset.
- Updates parsed chips in place while typing, so the entry stays focused and keystrokes are not lost during panel reconstruction.
- Saves parsed task dates as well as times and priorities. Date-only tasks remain dated in To-do and the daily agenda without being assigned a fake time.
- Aligns the capture mode and date labels with the v2 preview.

## Package

- `Perdana-Island-GNOME-v78.3.shell-extension.zip` for GNOME Shell 50 and 51.

This is a local build. It has not been pushed or published as a GitHub release.
