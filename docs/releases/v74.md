# Perdana Island v74

## GNOME Shell extension

- Adds **Settings → Island → Font** choices for Cantarell, Noto Sans, and Plus Jakarta Sans. The selected family is stored in local preferences and applied to island labels, buttons, and entries.
- Uses Cantarell if the saved font choice is missing or invalid. Plus Jakarta Sans is selected by family name and must be installed on the system; CSS falls back to Cantarell if it is absent.
- Fixes auto-close when an island opened by clicking loses pointer hover. It closes after a short grace period unless a drag is active.

## KDE Plasma package

No widget feature changes. Package metadata is aligned to v74.

## Packages

- `Perdana-Island-GNOME-v74.shell-extension.zip` for GNOME Shell 50 and 51.
- `Perdana-Island-KDE-Plasma-v74.zip` for KDE Plasma 6.
