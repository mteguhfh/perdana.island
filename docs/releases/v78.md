# Perdana Island v78 feature summary

## GNOME Shell extension

- **Quick capture**: the + beside the clock, or Ctrl+Alt+N. One line, a live preview (mode, title, date, time, priority), Enter adds a task, Ctrl+Enter saves a note, Esc closes. The parser runs locally.
- **Messages**: chat apps (WhatsApp, Discord, Telegram, Google Chat) are on their own page, grouped by sender, with Mark read and Clear.
- **Notifications**: Alerts and Activity tabs. Activity shows downloads from ~/Downloads (`.part`, `.crdownload`, `.download`, `.opdownload`). A compact pill shows the running item when no music or focus is playing.
- **Shelf**: Files | Clipboard switch. Clipboard keeps up to 25 entries.
- **Summary**: music on the left, Focus, To-do, and Messages on the right.
- **Reminders**: Prayer | Water split tabs. Log glass restarts the hour.
- **Browser logos**: Microsoft Edge, Google Chrome, Firefox, Brave, Opera, and Vivaldi alerts show the browser's logo, with a switch for each in Settings.
- **Settings**: Messages section (chat sources) separated from Notifications (system sources). New Data section with Save backup and Restore backup.
- **Backup**: one JSON file with tasks, notes, settings, and focus history. Clipboard and Shelf files are not included. Restore asks for confirmation and keeps a copy of the current data as `pre-restore.json`.
- **To-do**: the Tasks page is named To-do.

## Known limits

- The download watcher reads file names and sizes only. Its completion check was verified with a finished file; live browser downloads still need a real desktop test.
- Backup uses the desktop file dialog when the portal answers. Without it, Save and Restore use the app's backups folder. The dialog itself was not exercised headless.
- Browser detection matches the source name GNOME reports. Pattern `edge` can match an unrelated app with that word in its name.

## Package

- `Perdana-Island-GNOME-v78.shell-extension.zip` for GNOME Shell 50 and 51.

No KDE Plasma archive is included in this candidate.
