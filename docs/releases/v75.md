# Perdana Island v75

## GNOME Shell extension

- Fixes Spotify detection for songs whose title contains film-related words such as “Movie”. The spoken-content title heuristic no longer overrides a recognized music-service source.
- Removes trailing soundtrack attributions such as `- From "Film Name" Movie` from lyric search titles so LRCLIB receives the song name rather than the release annotation.
- Treats LRCLIB HTTP 5xx responses as temporary service errors and honors `Retry-After`, retrying instead of leaving lyric finding stuck after an overload.
- Includes v74's font selection and click-away fixes.

## KDE Plasma package

No widget feature changes. Package metadata is aligned to v75.

## Packages

- `Perdana-Island-GNOME-v75.shell-extension.zip` for GNOME Shell 50 and 51.
- `Perdana-Island-KDE-Plasma-v75.zip` for KDE Plasma 6.
