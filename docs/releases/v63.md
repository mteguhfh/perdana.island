# Perdana Island v63

## GNOME Shell

- Removed the remaining black corners from rounded cover artwork in Glass mode. Artwork corners are now transparent, so the island surface shows through.
- Removed the rectangular Shell blur effect that caused dark rectangular artifacts around rounded glass surfaces. Glass keeps its translucent navy treatment and rounded silhouette.
- Synced the latest local GNOME extension source and its GSettings schema into the clean release project.
- The package includes a compiled settings schema so preferences load from the installed archive.

## KDE Plasma

- Reissued the KDE Plasma widget as v63 to keep the two platform archives on the shared project release number. KDE widget code did not change in this release.

## Verification

- JavaScript syntax, extension metadata, and GSettings schema validated.
- GNOME and KDE release archives built locally; the GNOME archive contains the compiled schema and license.
- The rounded alpha mask was checked with sample artwork. The running Shell still needs to reload v63 before confirming the cover corners in the installed UI.
- GNOME Extensions review and approval are pending.
