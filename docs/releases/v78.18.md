# Perdana Island v78.18

## Fixed

- Match Google Chat notifications using app/PWA identity and its standalone or Gmail-hosted web address. Identified messages are routed to Messages and the web address is hidden from the message body.
- Keep automatic Water reminder timing separate from the manual glass log. The reminder countdown can advance without changing the last-glass record.
- Start an explicit manual water-log record with the first **Log glass** action after upgrading; the prior shared timestamp is not treated as a confirmed manual log.
- Keep reminder and water-log timestamps local to this device and out of exported backups.

Google Chat routing still needs the app name or site origin to be included in GNOME notification metadata. A generic browser source with no site identity cannot be mapped safely.

This is a local build. It has not been published to GitHub.
