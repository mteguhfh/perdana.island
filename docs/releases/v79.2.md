# Perdana Island GNOME v79.2

Maintenance release for GNOME Shell 50 and 51. Behavior, interface, and stored
data are unchanged from v79.1. KDE Plasma stays on its separate v76 package and
version track.

## Changes

- Splits the GNOME source into focused modules under `extension/`: pure domain
  logic for tasks, notes, focus, reminders, preferences, clipboard, Shelf,
  notifications, and progress; page renderers that take explicit inputs and
  callbacks; and runtime helpers for file persistence and battery reads.
  `extension/extension.js` remains the entry point and drops from 11,866 to
  9,147 lines.
- Persistence goes through one helper with the same file locations and the same
  clipboard permission modes (directory `0700`, file `0600`).
- Removes a duplicate Activity progress-bar child that produced a Clutter
  `add_child` warning.
- Fixes Shelf's Clipboard tab, which failed to render after the split because a
  module used `Clutter` without importing it.
- `scripts/validate.sh` now also checks that every runtime module imports the
  GNOME libraries it uses (`scripts/check-gi-imports.py`).

## Verification

- `npm test`: 72 unit tests pass.
- `./scripts/validate.sh`: JavaScript syntax, GI import check, JSON metadata,
  schema compilation, unit tests, and GNOME/KDE package contents pass.
- An isolated GNOME Shell 50.6 headless session rendered every page and every
  Settings section without overflow. The Settings navigation column stayed clear
  of the content column.
- Quick Capture showed the expected chips for a sample entry.
- Seventeen screenshots were compared with v79.1 using the same synthetic data.
  Fifteen matched exactly; the rest differed only in live clock, date, and
  system-metric text.
- On the Fedora GNOME Shell 50.6 desktop after login: synced lyrics, notifications,
  tab drag and reorder, and Shelf (including Clipboard) worked.

## Not changed or not verified

- Dragging files onto the island is not available; GNOME does not provide the
  dragged file list to the extension. Add files through **Add files** or copy
  them into the Shelf folder.
- The screenshot-to-Shelf button was not separately verified live.
- X11 has not been tested.

## Scope

No new features, no data format changes, and no KDE widget changes.
