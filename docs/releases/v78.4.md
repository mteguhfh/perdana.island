# Perdana Island v78.4

## Fixes

- Rebuilds Summary to match the v2 preview: album cover, title and artist, synced lyric, seek bar, and previous/play/next controls.
- Keeps Summary's focus, To-do, and Messages cards current while their underlying state changes.
- Updates Summary's playback controls when a media player starts, pauses, resumes, or changes tracks.
- Refreshes Summary as soon as background lyric lookup completes, including when the player is paused.
- Draws the tab bar and Summary card icons in the same light outline style as the preview.
- Refreshes the Shelf Clipboard count and history when new text is copied, without duplicating identical entries.
- Keeps Shelf Files and Clipboard content inside one panel viewport so the list remains visible and scrollable.

## Package

- `Perdana-Island-GNOME-v78.4.shell-extension.zip` for GNOME Shell 50 and 51.

This is a local build. It has not been pushed or published as a GitHub release.
