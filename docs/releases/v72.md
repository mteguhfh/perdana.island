# Perdana Island v72 candidate

## GNOME Shell extension

- Adds a **Notifications** side section in Settings.
- Adds a master switch for island banners and individual switches for WhatsApp Web, Discord, Telegram Web, Telegram Desktop, and Google Chat.
- Filters disabled app sources from the island's notification list and suppresses their island banners. GNOME's own notifications are unchanged.
- Shows the recognized app name and themed icon in banners. Selecting a banner activates its original GNOME notification.
- Keeps notifications from other applications available in the island list.
- Adds a saved Notch/Pill shape choice. Pill floats below the screen edge with fully rounded corners.
- Adds optional browser tuck-away: when a browser overlaps the island's top area and the pointer reaches the top edge, the island shrinks to a small handle. Move away to restore it, or click it to open.
- Shows an island brightness OSD when a supported hardware brightness key is pressed and the current backlight level is readable. GNOME still performs the brightness adjustment; the extension only displays the resulting level.

GNOME and browser notification sources vary by application. Website notifications can be separated only when GNOME exposes the website or app name; a generic browser source cannot be reliably attributed to an individual site.
Inline replies are not sent by the extension; clicking an app banner activates the original desktop notification. Brightness OSD is unavailable if the system does not expose a readable backlight level or the brightness key is intercepted before it reaches GNOME Shell.

## KDE Plasma package

There are no KDE feature changes in v72. Its package version is aligned with GNOME for the shared release.

## Packages

- `Perdana-Island-GNOME-v72.shell-extension.zip` for GNOME Shell 50 and 51.
- `Perdana-Island-KDE-Plasma-v72.zip` for KDE Plasma 6.
