# Perdana Island v69

## GNOME Shell

- Clipboard previews now mask the whole email address when the local part contains dots. `john.doe@example.org` shows as `j•••e@e•••e.org` instead of leaving the domain visible.
- Credential filtering now skips labeled API keys, access and refresh keys, generic token fields, client secrets, authorization values, and private keys. The check still targets named fields so ordinary text is not hidden.
- The extension declares support for GNOME Shell 50 and 51. Shell 51 removed the `St.BoxLayout.vertical` property, so the interface uses `Clutter.Orientation.VERTICAL`, which both releases provide.
- Clipboard helpers moved to `extension/clipboard-utils.js` and are covered by six unit tests. A validation script and CI workflow check syntax, metadata, the GSettings schema, version alignment, and both release archives.

## KDE Plasma

- The widget records clipboard changes while it is running, including when the popup is closed. It no longer depends on the Clipboard page being open.
- Clipboard entries skip KDE password-manager MIME data and text that matches the labeled credential list used by the GNOME extension.
- Plain text is truncated to 1,200 characters instead of being rejected, and recopying an entry moves it to the top.

## Packages

- `Perdana-Island-GNOME-v69.shell-extension.zip` is the GNOME Shell package and GNOME Extensions upload archive.
- `Perdana-Island-KDE-Plasma-v69.zip` is the KDE Plasma 6 package.

## Verification

- `npm test`: six unit tests pass.
- `./scripts/validate.sh`: JavaScript syntax, JSON metadata, GSettings schema, GNOME and KDE version alignment, and archive contents pass.
- GNOME Shell 51.0 on Ubuntu 26.10: the headless Wayland smoke test covered enable and disable, every page, notices, and preferences. The merged extension loaded in a live GNOME Shell 51.0 session with state `ACTIVE` and no Perdana Island errors.
- GNOME Shell 50 support uses `Clutter.Orientation.VERTICAL`, which exists in both Shell 50 and Shell 51. v69 was not re-run on Shell 50.
- The KDE archive builds successfully. The widget was not runtime-tested on Plasma 6 for this release.
