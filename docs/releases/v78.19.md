# Perdana Island v78.19

## Fixed

- Recognize the installed Microsoft Edge Google Chat PWA desktop ID when GNOME includes it in notification source metadata. The extension can route such notifications to Messages after Edge emits them.
- Update download activity rows in place instead of rebuilding and fading the whole Activity page every second.
- Keep completed downloads in Activity until the user selects the row. Selecting it opens the downloaded file and removes the entry.
- Remove a download from Activity when its partial file disappears without a final file, rather than showing a false completion.

## Google Chat notification setup

This release does not generate notifications that Google Chat or Edge has not sent to GNOME. In the local Edge profile on this machine, `mail.google.com` is blocked and `chat.google.com` has no explicit allow rule. Enable **Allow chat notifications** in Google Chat, then allow notifications for both `https://chat.google.com` and `https://mail.google.com` in Edge site permissions. Google also recommends checking GNOME's notification settings and using Chat's **Show an example** action to confirm browser delivery.

This is a local build. It has not been published to GitHub.
