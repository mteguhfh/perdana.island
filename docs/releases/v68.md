# Perdana Island v68

## GNOME Shell

- Clipboard changes are captured while the extension is enabled, including when the island is collapsed or another page is open. Debouncing and stale-request handling prevent overlapping reads from creating repeated entries.
- Recopying an item already in the four-entry history moves it to the top instead of creating a duplicate. Existing duplicate entries are removed when history is loaded. URL comparison ignores scheme/host capitalization, default ports, trailing punctuation, and a final root slash.
- Narrowed password filtering to explicit credential formats and the exact KDE password-manager MIME hint. Ordinary random-looking text, IDs, and unrelated MIME names are no longer classified as passwords.
- Reworked rounded album artwork rendering with a transparent Cairo mask to avoid black corners in Glass mode.
- Updated the LRCLIB user-agent and GNOME extension metadata to v68.

## KDE Plasma

- Aligned the widget package version with the shared v68 release number. No KDE widget code changed in this release.

## Packages

- `Perdana-Island-GNOME-v68.shell-extension.zip` is the GNOME Shell package and GNOME Extensions upload archive.
- `Perdana-Island-KDE-Plasma-v68.zip` is the KDE Plasma 6 package.

## Verification

- JavaScript syntax and extension metadata validated.
- GSettings schema compiled and both platform packages built with the release packaging script.
- The GNOME archive contains the extension files, settings schema, and GPL license; the KDE archive contains the Plasma widget package.
