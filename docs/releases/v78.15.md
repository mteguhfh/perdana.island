# Perdana Island v78.15

## Fixed

- Remove temporary Pango layout and font-description objects from resting lyric measurement. GNOME Shell crash dumps showed heap corruption while Pango freed a font description during garbage collection.
- Limit lyric parsing to 500 lines and render only the active line with four lines of context on each side. This reduces text actors, layout work, and animations for long tracks.
- Preserve centered resting lyrics and wrapped-height fitting using the existing label's preferred-height measurement.
- Keep WhatsApp Web browser notifications routed to Messages without including the website address in the message preview.

This is a local build. It has not been published to GitHub.
