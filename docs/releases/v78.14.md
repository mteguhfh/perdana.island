# Perdana Island v78.14

## Fixed

- Measure resting lyric text with a width-constrained Pango layout rather than a one-pixel actor allocation. This keeps the active lyric visible, vertically centered, and fitted inside the fixed resting height.
- Recognize notifications from `web.whatsapp.com` delivered through Edge or another supported browser as WhatsApp messages and route them to Messages.
- Remove the WhatsApp Web site address from the sender/message preview while preserving the sender and actual message text.
- Flatten notification line breaks and clip single-line sender, app, and message fields to their card allocations so content stays inside Notifications and Messages.

This is a local build. It has not been published to GitHub.
