# Perdana Island v78.16

## Messages and chat notifications

- Route browser notifications identified as WhatsApp Web, Google Chat, or Telegram Web to Messages instead of Alerts.
- Remove recognized chat website addresses from displayed message text.
- Show a Reply button only when GNOME exposes a Reply/Respond action from the originating application, and invoke that exact action.

GNOME notifications do not provide extensions with a generic text-entry reply channel. If the browser or chat app sends only an open/activate action, Messages continues to open the conversation and does not show a misleading reply control.

This is a local build. It has not been published to GitHub.
