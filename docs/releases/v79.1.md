# Perdana Island GNOME v79.1

Patch release for GNOME Shell 50 and 51. KDE Plasma stays on its separate v76
package and version track.

## Changes

- Reworks the Messages header so sender and latest-message preview occupy a
  dedicated text column, while the timestamp stays aligned at the upper right.
  Long previews ellipsize on one line and no longer get clipped by the unread
  count column.
- Removes unread-number badges from individual conversation cards. The page
  unread total, unread row treatment, per-message unread dots, `Mark all read`,
  and `Clear` remain available.
- Keeps the message list within the available island height. Expanding a card
  recalculates layout naturally, scrolls it into view, and moves later cards
  instead of covering them.
- Removes known WhatsApp, Telegram, and Google Chat website labels from chat
  notifications while keeping links to unrelated websites in message content.
- Preserves the existing notification sources, grouping, open action, and
  mark-read behavior.
- Updates the GNOME extension version and archive to `v79.1`; KDE remains at
  v76.

## Verification

- `./scripts/validate.sh` passes: JavaScript syntax, JSON metadata, schemas,
  all 37 unit tests, and GNOME/KDE package contents.
- The Fedora GNOME Shell 50.6 session was not reloaded for this release. The
  packaged UI changes require a new login to appear in the running shell; no
  live post-release visual check is claimed.

## Scope

This release contains no cross-monitor movement and does not change the KDE
widget.
