# Perdana Island v71

## GNOME Shell extension

- Classifies MPRIS sessions before showing the resting music pill or music page. It uses the player identity and available content type, genre, title, artist, album, URL, and track duration.
- Recognizes music from Spotify, YouTube Music, YouTube, Deezer, SoundCloud, Apple Music, Tidal, Amazon Music, Bandcamp, Pandora, Qobuz, and Napster when track metadata supports that classification.
- Filters podcasts, spoken programs, films, television, social videos, and unclear media. If a non-music session is actively playing, a previously selected paused song is not left visible as stale music.
- Adds a **Smart detection** switch under **Settings → Island**. It is on by default and can be turned off.
- Refines the Notes page's safe insets, editor padding, and list sizing so its controls stay within the panel.
- Guards the Keep awake session-inhibitor request against delayed responses after the setting is switched off or the extension is disabled.

## KDE Plasma package

There are no KDE feature changes in v71. Its package version is aligned with GNOME for the shared release.

## Packages

- `Perdana-Island-GNOME-v71.shell-extension.zip` for GNOME Shell 50 and 51.
- `Perdana-Island-KDE-Plasma-v71.zip` for KDE Plasma 6.
